# CLAUDE.md

## Documentation

- When a change affects behavior, providers or configuration, update `README.md` in the same change.

## Git

- Never commit on your own. Always propose the commit (files and message) and wait for explicit approval before running `git commit`.
- Ask before creating or switching branches. Propose the branch name first and wait for approval.
- Do not add a `Co-Authored-By: Claude` (or any other Claude attribution) line to commit messages or PR descriptions.
- Never push. The user always pushes themselves.
